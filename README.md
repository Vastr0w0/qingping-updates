# 清屏 Android 更新

此仓库仅发布清屏的 Android 安装包、版本清单、签名规则库和更新说明，不包含用户数据或签名私钥。

安装最新版请前往 [Releases](https://github.com/Vastr0w0/qingping-updates/releases/latest)。首次安装 0.2.0 后，可在“设置 → 检查应用更新”中获取后续版本；无需 GitHub 账号。已经安装 0.1.0 的用户需手动覆盖安装一次 0.2.0。

应用下载后核对文件大小、SHA-256、包名、版本和当前签名，再交给安卓系统确认安装。首次可能需要手动允许来自清屏的安装；不支持静默安装。覆盖更新保留本机规则与统计，请勿先卸载。

0.3.0 新增“自动保护全部应用”：首次安装默认使用，旧版升级保留原选择并提示一键切换。授权并显示“✓ 服务已连接”后，直接使用其他 APP 即可，无需逐个配置。可排除单个应用，个别广告可主动录制跳过控件。指定广告跳转退回须单独设置。

首页和设置页分别用对勾显示真实授权、连接状态；新增临时暂停、按应用放行、快捷磁贴、本机诊断、规则备份导入，以及按尝试与确认分别统计。规则库独立检查、校验签名后预览应用，可回退；首批 8 个模板采用通用识别，尚未完成商业 APP 实机适配。

无障碍识别、统计与简要诊断均在本机处理，不截图、不保存页面文字，不上传记录。录制只保存选定控件 ID 与应用版本。仅在你检查应用或规则更新时访问 GitHub；部分网络环境可能不可达，可以稍后重试。

清屏通过用户手动授权的无障碍服务处理能识别的开屏跳过按钮，对明确指定的广告跳转事后尝试返回。它不能提前阻止任意跳转，也不保证永久保活、开机必定恢复或所有广告均可处理。强行停止或系统策略可能要求用户重新开启服务。权限勾选不代表已获得商店审核批准。

这是个人签名的本地试用版，最低 Android 8.0。Google Play 将干预其他应用广告展示列为违规示例，本项目不承诺符合 Play 上架要求。
