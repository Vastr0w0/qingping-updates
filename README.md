# 跳过人生 Android 更新（原清屏）

此仓库仅发布跳过人生的 Android 安装包、版本清单、签名规则库和更新说明，不包含用户数据或签名私钥。

0.4.3 默认隐藏已开启的侧边“跳”按钮，保留透明、不可触摸的后台兼容层；未开启兼容模式的用户不会被自动开启。首页和设置显示实际附着状态，检查与修复可随时恢复可拖动按钮。隐藏模式在小米等厂商系统上的后台效果需要对照复测，不保证与可见模式始终相同。暂停、锁屏、关闭后台保护/总开关或服务断开后移除。

大麦9.0.32（109003200）新增精确开屏ID `cn.damai:id/homepage_advert_pb`的原生查询与点击适配，可绕开通用文字及400节点有限遍历的遗漏；未提高全局遍历上限。默认8秒时窗、用户开关与几何校验保留。若控件不可原生点击，将记录具体原因并保持不操作。本版没有新增无障碍手势能力，服务仍声明`canPerformGestures=false`，因此仍无法处理依赖中心手势点按的广告。大麦实际效果仍需实机复测。

0.4.2 为哔哩哔哩9.8.0（versionCode 9080300）加入`count_down`、`skip`两个完整资源ID的开屏控件适配，随应用升级自动生效，无需导入rules。仅这两个ID使用已有的精确控件范围策略，通用文字不放宽；用户精确ID优先，应用排除、关闭跳过、暂停和默认8秒时限均保留。其他应用不启用这项适配，B站版本变化后回到通用或用户规则。公开ID与用户日志只提供定位线索，不代表已经在真实B站广告上验证成功。

新版单应用诊断会显示“内置控件适配”、命中次数，以及最近候选的坐标和校验结果。后续无候选扫描不会覆盖这条线索；只记录元数据和内置已知ID，不保存页面文字、截图或上传。支持范围仍以开屏为主，首页推荐、视频播放中的广告及同次进入连续两次开屏不在本次新增支持范围。保持已有后台保护/浮标选择，直接覆盖安装即可；签名规则库仍为版本1。

0.4.1 增加可选“后台兼容浮标（实验）”。如果后台保护已经启动，但目标应用仍然扫描0、对应窗口0，可在“首页 → 检查与修复”中手动开启；屏幕左侧出现可上下拖动的“跳”按钮，点按打开跳过人生。它只接收按钮范围内的触摸，不抢焦点。暂停、息屏/锁屏、关闭总开关或后台保护、录制以及无障碍断开时移除。默认关闭，升级不会自动启用，不新增权限。兼容效果仍需在具体机型验证，不保证永久保活，也不代表百度地图或全民K歌已适配。

后台保护运行时分别采样主线程和工作线程，只比较当前亮屏解锁区间的间隔；息屏/锁屏空档不再计入该区间最大间隔。单应用诊断自带最多24条最近后台与窗口核验元数据，无需额外开始自检；不截图、不保存页面文字、不上传。后台保护已启动时，零窗口结论不再提示重复开启或重新授权。B站未出现广告继续记为未验证。

网上的rules格式并不通用。跳过人生默认启用通用识别；现有导入入口只恢复清屏/跳过人生的规则备份，会替换已有自定义规则，无法直接导入GKD JSON5订阅。只有读到目标应用的广告控件后，专用规则才能参与匹配。

安装最新版请前往 [Releases](https://github.com/Vastr0w0/qingping-updates/releases/latest)。首次安装 0.2.0 后，可在“设置 → 检查应用更新”中获取后续版本；无需 GitHub 账号。已经安装 0.1.0 的用户需手动覆盖安装一次 0.2.0。

应用下载后核对文件大小、SHA-256、包名、版本和当前签名，再交给安卓系统确认安装。首次可能需要手动允许来自本应用的安装；不支持静默安装。覆盖更新保留本机规则与统计，请勿先卸载。

0.4.0 起应用更名为“跳过人生”（原“清屏”）。包名 cn.qingping.app、安装签名、数据库和规则备份协议保持兼容，旧用户可直接覆盖安装，规则、统计及后台保护选择保留。桌面、无障碍服务、通知和新导出文件使用新名称；旧备份仍可从本应用导出文件中恢复。

首页增加后台保护实际状态、最近一次成功和“检查与修复”入口。首次开启后进入逐项引导，分别检查总开关、无障碍授权、实际服务连接、后台保护及20秒自检；后台保护仍由用户主动选择，不静默授权。

诊断先显示基于记录的结论，原始元数据折叠到“详细信息”，复制时仍包含完整报告。区分没有事件、没有对应窗口、证据不足、候选无法执行、操作待确认、最近结果未确认及自检采样间断，不把空窗口直接归因为系统拒绝权限。

统计的最近记录支持误触反馈：停用该应用当前的开屏跳过或指定退回规则、临时放行10分钟，或仅标记。反馈单独保存并去重，原操作和统计历史保留；不会自动撤销已发生的点击。应用更新导致精确ID过期时，明确停用的跳过开关仍会保持关闭。

针对部分设备事件迟到、仅部分应用有效的问题，后台保护开启且屏幕亮着时约每900ms核对实际前台窗口，至少间隔1800ms进行不依赖本地缓存的读取。Android 13+ 使用公开缓存API并恢复原设置，事件线索不再受诊断快照保存次数影响；事件来源与当前事件分别记录各自时间。控件匹配仍只在本次进入后的有限时窗内进行，继续检查主屏、包名、焦点、控件范围和真实结果；不新增权限、坐标点击、截图或持续唤醒锁。

这个改进针对事件缺失与缓存滞后路径，不声称已完成百度地图、全民K歌、哔哩哔哩的实机适配。厂商后台策略、系统不可访问控件和不同广告样式仍可能影响效果；耗电与具体机型表现需继续观察。

0.3.4 增加可选的“后台运行保护”和限时20秒自检。后台保护默认关闭，开启后使用声明了 specialUse 用途的前台服务与持续通知，尝试改善后台执行；只有服务实际启动才显示对勾。关闭总开关、关闭该选项或无障碍服务断开后停止。它不提供额外窗口读取能力，也不保证厂商清理后一直运行。新增两项普通声明权限 `FOREGROUND_SERVICE` 与 `FOREGROUND_SERVICE_SPECIAL_USE`，不需要额外的屏幕访问授权。

新版记录无障碍事件原始 uptime、清屏收到事件的 uptime 和送达延迟，保留最大延迟。迟到事件不按送达时间重新开启完整点击时窗，也不会被误当成当时源控件不可读的证明。20秒自检分别记录主线程、工作线程执行间隔、回调/查窗/扫描耗时及清屏前后台切换，只在你主动开始时额外采样，到时自动结束；锁屏、暂停、改设置或服务断开也会结束。报告可预览、复制，只有窗口元数据与时序，不记录页面文字或截图，不上传。

排查入口：“设置 → 开始20秒后台自检” → 打开有广告的应用并停留约10秒 → 返回清屏，等观察结束 → “查看 / 复制自检报告”。可以分别在后台运行保护关闭和开启时对照。旧报告未包含原始事件时间，不能据此断言系统拒绝窗口；同机其他工具能跳过也说明仍需查清屏自身的执行差异。小米 Android 17 的具体根因和修复效果仍待实机报告确认。

0.3.3 是主屏兼容与诊断更新：窗口选择按手机主屏隔离，避免其他逻辑显示屏的焦点参与自动操作；结果确认和规则录制也统一使用主屏。遇到近期窗口事件与实际读取结果冲突时，Android 13+ 会限频刷新节点缓存重读。外接屏、虚拟屏自动操作暂不支持。

诊断保留事件当时的屏幕编号、来源和窗口元数据，每应用保留最近两个事件窗口最初两次核验，返回清屏后不会覆盖这些记录。只保留包名、编号、类型、层级、范围和状态标记，不记录截图、页面文字或窗口标题，也不上传报告。遇到问题后，在“应用 → 对应应用 → 查看这个应用的诊断”复制单应用报告。

0.3.3 尚未在小米 Android 17 上验证，持续零扫描的实机根因仍待事件当时的信息确认；不将这次兼容改进宣称为百度地图或网易云音乐已适配成功。

0.3.2 针对“已经收到广告应用事件，但扫描次数仍为 0”修复扫描调度：交错的后台、键盘或系统组件事件不再直接抢占目标，已排队的扫描不被反复推迟。扫描时先核验实际前台窗口，再按其应用规则处理。重复日志按应用合并，事件计数保留。首页显示“服务已就绪”和最近实际扫描结果，避免把服务连接等同于已经处理广告。

这条故障路径已在隔离 Android 15 环境复现，并在相同 150 个交错事件干扰下验证修复版完成真实跳过和确认；尚未在小米 Android 17 的百度地图、网易云音乐实际广告上验证。

0.3.1 改进应用切换时的窗口定位：遇到空窗口或上一款应用的窗口会在原识别时窗内重试，也会检查无包名的窗口变化事件。增加对延迟出现、层级较深、带分隔符和分离倒计时的跳过控件识别。桌面排除只针对当前默认桌面，避免将声明桌面能力的其他应用误排除。

遇到没有跳过的广告，打开“应用 → 对应应用 → 查看这个应用的诊断”，可复制该应用的版本、有效规则、事件数、扫描数、读到对应窗口次数和未执行原因。全局诊断也保留按应用的事件摘要，时间使用手机本地时区。诊断只记录元数据，不记录页面文字或截图。

0.3.1 已在 Android 15 模拟器验证通用场景；小米 Android 17 和百度地图实际开屏仍需实机复测，不能由这些结果推断已适配成功。

0.3.0 新增“自动保护全部应用”：首次安装默认使用，旧版升级保留原选择并提示一键切换。授权并显示“✓ 服务已连接”后，直接使用其他 APP 即可，无需逐个配置。可排除单个应用，个别广告可主动录制跳过控件。指定广告跳转退回须单独设置。

首页和设置页分别用对勾显示真实授权、连接状态；新增临时暂停、按应用放行、快捷磁贴、本机诊断、规则备份导入，以及按尝试与确认分别统计。规则库独立检查、校验签名后预览应用，可回退；首批 8 个模板采用通用识别，尚未完成商业 APP 实机适配。

无障碍识别、统计与简要诊断均在本机处理，不截图、不保存页面文字，不上传记录。录制只保存选定控件 ID 与应用版本。仅在你检查应用或规则更新时访问 GitHub；部分网络环境可能不可达，可以稍后重试。

清屏通过用户手动授权的无障碍服务处理能识别的开屏跳过按钮，对明确指定的广告跳转事后尝试返回。它不能提前阻止任意跳转，也不保证永久保活、开机必定恢复或所有广告均可处理。强行停止或系统策略可能要求用户重新开启服务。权限勾选不代表已获得商店审核批准。

这是个人签名的本地试用版，最低 Android 8.0。Google Play 将干预其他应用广告展示列为违规示例，本项目不承诺符合 Play 上架要求。
